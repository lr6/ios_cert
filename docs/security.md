# 安全设计说明

> 本文件如实说明本工具能防什么、不能防什么。**请勿把浏览器存储当作绝对安全**。

## 1. 数据在哪里

| 数据 | 存放位置 | 保护方式 |
| --- | --- | --- |
| 证书元信息、CSR、CER | 浏览器 IndexedDB | 明文（这些本身不是秘密） |
| 私钥 | 浏览器 IndexedDB | AES-256-GCM 密文 |
| 本地主密钥 | 浏览器 IndexedDB | **不可导出**的 `CryptoKey` 对象（结构化克隆存储） |
| P12 导出密码 | 不存储 | 仅在该次操作的内存中存在 |
| 备份密码 | 不存储 | 仅用于派生密钥，派生结果用完即弃 |
| 备份文件 | 用户自己保存 | AES-256-GCM 密文，密钥来自备份密码 |

任何数据都**不会**上传到服务器：站点不包含任何后端 API 调用，CSP 也限制 `connect-src 'self'`。

## 2. 加密参数

| 用途 | 算法与参数 |
| --- | --- |
| 私钥封装 | AES-256-GCM，12 字节随机 nonce，128 位 tag；AAD = `ioscert-key\|<certificateId>` |
| 主密钥自检 | AES-256-GCM，AAD = `ioscert-vault`，明文为固定串 |
| 备份加密 | AES-256-GCM，12 字节随机 nonce；AAD = `ioscert-backup\|v1` |
| 备份密钥派生 | PBKDF2-HMAC-SHA256，600000 次迭代，16 字节随机盐（每次备份独立） |
| CSR 签名 | RSA PKCS#1 v1.5 + SHA-256 |
| 随机数 | `crypto.getRandomValues` / Web Crypto 内部 CSPRNG（不使用 `Math.random`） |
| P12 私钥加密 | PBES2 + PBKDF2-HMAC-SHA1 + AES-256-CBC（可切换 3DES 兼容模式），MAC 为 HMAC-SHA1 |

P12 使用 AES-256-CBC 是因为要兼顾 Apple 生态的兼容性；如需更"传统"的兼容模式，可在导出对话框中选择 3DES。

## 3. 威胁模型

### 能防住

- **静态数据被翻看**：直接打开 IndexedDB 或备份文件，看不到明文私钥；
- **文件误传**：备份文件是密文，泄露文件本身不足以恢复私钥（还需要密码）；
- **密文替换/篡改**：AES-GCM 的 AAD 绑定证书 id 与备份信封头，篡改会导致解密失败；
- **误操作**：删除/清空/替换恢复等危险操作都有二次确认，删除时可选择是否同时删除私钥；
- **静默失败**：所有密码学错误都会显式抛出并展示真实原因，不会伪造成功。

### 防不住（必须知晓）

1. **页面被恶意脚本控制**：如果站点被入侵、浏览器扩展注入脚本、或你访问了伪造的镜像站点，攻击者可以在页面上下文里调用主密钥解密私钥。**本地存储的加密强度无法抵御这种情况。**
2. **设备被完全控制**：键盘记录、屏幕录制、内存转储等都可获取明文或密码。
3. **浏览器数据被清理 / 无痕模式 / 更换设备**：主密钥丢失后，已保存的私钥密文将无法解密（备份文件不受影响）。
4. **明文密钥在内存中的生命周期**：JavaScript 无法保证内存被彻底擦除，代码只是尽量缩短引用生命周期并主动清零缓冲区。
5. **Apple 侧状态**：证书链完整性、证书吊销、账号权限、证书在 Xcode 中是否可用，都无法仅凭本地文件判断。

## 4. 相关实现措施

- **CSP**（`public/_headers`）：`default-src 'self'`、`script-src 'self'`、无第三方域、`object-src 'none'`、`frame-ancestors 'none'`；仅 `style-src` 允许 `'unsafe-inline'`（Element Plus / Vue 会写入内联样式）；
- 其他响应头：`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`X-Frame-Options: DENY`、`Permissions-Policy` 关闭无关能力；
- 构建产物检查：`npm run check:dist` 扫描 `dist/` 中是否混入 PEM 私钥/证书或测试密码；
- 代码规范：ESLint 中 `vue/no-v-html` 为 error，禁止任何 `v-html`（避免 XSS 注入面）；
- 日志：不打印私钥、P12 密码、备份密码与文件内容（`console.warn` 仅用于存储层异常提示）。

## 5. 使用建议

- 只在**自己的设备**与**你自己部署的域名**上使用；不要在不可信的电脑或来源不明的镜像站点上使用；
- 及时导出备份，并把备份文件与 P12 存放在加密磁盘或密码管理器中；
- P12 导出密码建议 ≥ 12 位随机字符；备份密码同理，且不要与 P12 密码相同；
- 重要证书建议同时在 macOS 钥匙串中保留一份（通过 P12 导入），不要只依赖浏览器存储。
